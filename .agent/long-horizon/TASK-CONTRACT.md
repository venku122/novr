# Baseline diagnostics contract
Scope: read-only raw/profile/action diagnostics and independent safe staging/deployment utility. Protected: HOTAS, mouse/keyboard, existing controller actions, pointer/camera behavior, installed binaries/configs. Validation: compare live hashes, compile runtime/patcher, serialize diagnostic DTO with deterministic checks, test build-deploy suppression and temporary-tree deploy/rollback/tamper/running-game safety. Hardware remains unverified. Budget: three attempts per failure signature. Rollback: git revert isolated changes or keep previous immutable stage; no live deploy in this attempt.
